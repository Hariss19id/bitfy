# Bitfy Releases

Repositori ini khusus digunakan untuk menampung berkas rilis resmi (APK) dan metadata pembaruan aplikasi **Bitfy**.

## Informasi Keamanan & Struktur Proyek
- **Source Code**: Kode sumber utama aplikasi Bitfy disimpan di repositori terpisah secara privat untuk keamanan. Repositori ini hanya berisi biner aplikasi akhir.
- **Unduhan**: File APK dirilis melalui halaman **Releases** di GitHub ini, dan dialihkan secara dinamis melalui domain `download.bitfy.my.id` untuk digunakan oleh in-app updater.
